# LINE → Google カレンダー 予定取込 Bot

LINE に投稿されたメッセージから日時・件名・場所を読み取り、Google カレンダーへ自動で登録する Bot です。
LINE Messaging API と Google Apps Script（GAS）だけで動き、サーバーの用意は不要です。

```
  LINE（個人トーク / グループ）
        │  ふだんどおりメッセージを投稿
        ▼
  LINE Messaging API  ──Webhook──▶  Google Apps Script（ウェブアプリ）
                                          │  日本語の日付・時刻を解析
                                          ▼
        ◀── 「この予定を登録しますか？」──  確認（グループの通常投稿）
        │  ［登録］を押す
        ▼
  Google カレンダー に予定を作成 ──▶ 登録結果を LINE に返信
```

## できること

| 入力例 | 登録される予定 |
| --- | --- |
| `9/15 14:00 現場打合せ @仙台営業所` | 9/15 14:00-15:00「現場打合せ」場所: 仙台営業所 |
| `9月15日(火) 10時〜12時 配筋検査` | 9/15 10:00-12:00「配筋検査」 |
| `明日 8時 朝礼` | 翌日 08:00-09:00「朝礼」 |
| `来週金曜 終日 社内研修` | 来週金曜の終日予定「社内研修」 |
| `9/15-9/17 出張` | 9/15〜9/17 の終日予定「出張」 |
| `20日 13:30 検査` | 直近の20日 13:30-14:30「検査」 |

- **グループでは投稿を自動で拾い、［登録］［やめる］のボタンで確認してから登録します。**
  押さないかぎりカレンダーには入らないので、会話に紛れた日時で予定が増えることはありません。
- 登録後は読み取った内容が LINE に返るので、間違いにその場で気づけます。
- `取消` と送れば直前の登録を削除できます。
- `一覧` でこれから 7 日間の予定を確認できます。
- グループごとに登録先カレンダーを分けられます（現場ごとのグループ → 現場ごとのカレンダー）。

## 必要なもの

- LINE アカウント（[LINE Developers](https://developers.line.biz/) にログインできること）
- Google アカウント（予定を登録するカレンダーの編集権限）

どちらも無料の範囲で運用できます。本 Bot は返信（reply）しか使わないため、LINE 公式アカウントの
無料プランにある「送信メッセージ数」の上限は消費しません。

## セットアップ

### 1. LINE 側のチャネルを作る

1. [LINE Developers コンソール](https://developers.line.biz/console/) にログインする。
2. プロバイダーを作成（既にあればそれを使う）。
3. **新規チャネル作成 → Messaging API** を選び、チャネル名などを入力して作成する。
4. **「Messaging API設定」タブ** を開く。
   - 下部の **チャネルアクセストークン（長期）** を「発行」し、値を控える。
   - **応答メッセージ** を「オフ」、**Webhook** を「オン」にする
     （「編集」リンクから LINE Official Account Manager が開きます）。
   - グループで使う場合は、LINE Official Account Manager の
     **設定 → 機能の利用 → グループ・複数人トークへの参加を「許可する」** にする。

### 2. Google Apps Script プロジェクトを作る

1. [script.google.com](https://script.google.com/) で **新しいプロジェクト** を作成する。
2. `src/` 配下の各 `.gs` ファイルを、同じ名前でプロジェクトに作成して中身を貼り付ける。
   - `Parser.gs` / `Config.gs` / `LineClient.gs` / `CalendarService.gs` / `Commands.gs` / `Webhook.gs` / `Tests.gs`
3. 左の **プロジェクトの設定** を開き、**タイムゾーンが「(GMT+09:00) 日本標準時」** になっていることを確認する。
   （`appsscript.json` を編集する場合は「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック）

<details>
<summary>clasp（コマンドライン）で流し込む場合</summary>

```bash
npm install -g @google/clasp
clasp login
clasp create --type webapp --title "LINE Calendar Bot" --rootDir src
# 生成された .clasp.json をこのリポジトリの line-calendar-bot/ 直下に置く
clasp push
```

`.clasp.json.example` を `.clasp.json` にコピーし、`scriptId` を書き換えても構いません。
`.clasp.json` は `.gitignore` 済みです。
</details>

### 3. スクリプトプロパティを設定する

GAS の **プロジェクトの設定 → スクリプト プロパティ** で以下を登録します。

| プロパティ名 | 必須 | 内容 |
| --- | :---: | --- |
| `LINE_CHANNEL_ACCESS_TOKEN` | ✅ | 手順 1 で発行したチャネルアクセストークン（長期） |
| `WEBHOOK_TOKEN` | ✅ | Webhook URL に付ける合言葉。32文字程度のランダム文字列を自分で決める |
| `CALENDAR_ID` | | 登録先カレンダー ID。省略すると自分のメインカレンダー |
| `SOURCE_CALENDAR_MAP` | | トークごとに登録先を変える。例: `{"Cxxxxxxxx":"abc@group.calendar.google.com"}` |
| `ALLOWED_SOURCE_IDS` | | 登録を許可する LINE の ID をカンマ区切りで。空なら全許可 |
| `CONFIRM_BEFORE_CREATE` | | 確認を挟む範囲。`group`（既定・グループのみ）/ `always` / `never` |
| `GROUP_MIN_CONFIDENCE` | | グループで拾い始める確からしさ。`high`（既定）/ `medium` / `low` |
| `GROUP_TRIGGER` | | 付けると確認なしで即登録する先頭キーワード（既定: `予定`） |
| `DEFAULT_DURATION_MINUTES` | | 終了時刻がないときの所要時間（既定: `60`） |

> `WEBHOOK_TOKEN` は `openssl rand -hex 16` などで生成してください。

カレンダー ID は、Google カレンダーの
**該当カレンダーの「設定と共有」→「カレンダーの統合」→ カレンダー ID** で確認できます。

### 4. ウェブアプリとしてデプロイする

1. 右上の **デプロイ → 新しいデプロイ** をクリック。
2. 種類の選択（歯車）で **ウェブアプリ** を選ぶ。
3. 設定：
   - **次のユーザーとして実行**: `自分`
   - **アクセスできるユーザー**: `全員`（LINE のサーバーから匿名で呼ばれるため必須）
4. **デプロイ** を押し、求められる権限（カレンダー／外部リクエスト）を承認する。
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/＊＊＊/exec`）を控える。

### 5. Webhook URL を LINE に登録する

手順 4 の URL の末尾に、手順 3 で決めた合言葉をクエリとして付けたものが Webhook URL です。

```
https://script.google.com/macros/s/＊＊＊/exec?token=ここにWEBHOOK_TOKENの値
```

これを LINE Developers の **Messaging API設定 → Webhook URL** に貼り付けて **更新** します。

> **「検証」ボタンはエラーになることがあります。**
> GAS のウェブアプリは内部でリダイレクトを返すため、LINE の検証ツールが失敗と表示する場合がありますが、
> 実際のメッセージ配信は正常に動きます。実機で試して確認してください。

### 6. 動作確認

1. LINE Developers の **Messaging API設定** にある QR コードから、自分の LINE で Bot を友だち追加する。
2. トークで `ヘルプ` と送る → 使い方が返ってくれば Webhook まで到達しています。
3. `9/15 14:00 テスト予定` と送る → カレンダーに登録され、確認メッセージが返ります。
4. `取消` と送ると、いま登録した予定が削除されます。

うまくいかない場合は GAS の **実行数 / ログ**（左メニューの「実行数」）にエラーが残っています。

## 使い方

### 個人トーク

Bot にメッセージを送るだけで登録されます。

```
9/15 14:00 現場打合せ @仙台営業所
```

### グループトーク

ふだんどおり投稿するだけです。日時らしきものを見つけると Bot が確認を返します。

```
［投稿］9/15 14:00から現場定例やります

［Bot］この予定を登録しますか？
       🗓 9/15(火) 14:00-15:00
       　現場定例やります
       ［登録］［やめる］
```

**［登録］を押したときだけ**カレンダーに入ります。押さずに放置しても何も起きません。

確認を飛ばして即登録したいときは、先頭に `予定`（`GROUP_TRIGGER`）を付けます。

```
予定 9/15 14:00 現場打合せ @仙台営業所
```

Bot をグループに招待してから、グループ内で `ID` と送ると、そのグループの ID が表示されます。
これを `SOURCE_CALENDAR_MAP` や `ALLOWED_SOURCE_IDS` に設定します。

#### どこから拾うか（誤反応の調整）

グループの通常の投稿は、**明示的な日付＋時刻（または終日）が揃ったとき**だけ確認を出します
（`GROUP_MIN_CONFIDENCE` の既定値 `high`）。

| 投稿 | 反応 | 理由 |
| --- | --- | --- |
| `9/15 14:00から現場定例やります` | 確認を出す | 日付＋時刻が揃っている（high） |
| `9/20 安全パトロール` | 出さない | 日付だけ（medium）。`GROUP_MIN_CONFIDENCE=medium` で拾える |
| `15日分の請求書送りました` | 出さない | 日にちだけの弱い手がかり（low） |
| `10時には着きます` | 出さない | 時刻だけ（low） |

`明日10時に現場行きます` のような会話も日付＋時刻が揃っているため確認が出ます。
その場合は［やめる］を押すか、そのまま放置してください（押さなければ登録されません）。

### 複数件をまとめて登録

1 行 1 件で書くと、まとめて登録されます（1 メッセージ最大 10 件）。

```
9/15 10:00 配筋検査
9/16 13:00 コンクリート打設
9/17 終日 現場休み
```

確認は 1 回にまとまり、［登録］を押すと全件が入ります。`取消` も一括で戻せます。

### コマンド

| コマンド | 動作 |
| --- | --- |
| `ヘルプ` | 書き方とコマンド一覧を表示 |
| `一覧` | これから 7 日間の予定を表示 |
| `取消` | 直前に登録した予定を削除 |
| `ID` | このトークの ID を表示（設定用） |

## 読み取りのルール

| 種別 | 対応する書き方 |
| --- | --- |
| 日付 | `9/15` `9月15日` `2026/9/15` `2026年9月15日` `2026-09-15` `20日` |
| 相対日付 | `今日` `明日` `あさって` `しあさって` `昨日` |
| 曜日 | `月曜` `今週水曜` `来週の金曜日` `再来週火曜` |
| 期間 | `9/15-9/17` `9/15〜9/17`（終日予定になります） |
| 時刻 | `14:00` `14時` `14時30分` `14時半` `午前10時` `午後3時` |
| 時間帯 | `10:00-12:00` `10時〜12時` `14時から16時まで` |
| 終日 | `終日` `全日` `一日中` / 時刻の記載がない場合も終日 |
| 場所 | `@仙台営業所` `場所：本社3階会議室` `会場：〇〇` |
| 件名 | 上記を取り除いた残り（空なら「予定」） |

補足:

- 全角（`９／１５　１４：００　＠仙台`）でもそのまま読み取れます。
- 終了時刻の指定がない場合は `DEFAULT_DURATION_MINUTES`（既定 60 分）で登録します。
- **午前／午後の指定がない `1時`〜`6時` は午後として扱います**（`2時` → 14:00）。
  現場の朝礼を誤変換しないよう `7時` 以降はそのままです。この境界は `Parser.gs` の
  `PARSER_CONFIG.pmShiftMaxHour` で変更できます。
- 年の指定がない日付は、基準日から 60 日以上前にならないよう年を推定します
  （9 月に `1/10` と書けば翌年 1 月 10 日）。
- 件名は入力した表記のまま登録します（`打合せ（仮）` はそのまま）。日付の前後に付いた助詞
  （`会議は9/15…` の `は`、`9/15の現場確認` の `の`）は取り除きますが、`はつり工事` や
  `のぞみ工務店` のように語の一部である場合は残します。
- 読み取り結果は必ず返信に表示されるので、違っていれば `取消` してから送り直してください。

## カスタマイズ

`src/Parser.gs` 冒頭の `PARSER_CONFIG` で解析の挙動を調整できます。

```js
var PARSER_CONFIG = {
  defaultDurationMinutes: 60,        // 終了時刻がないときの所要時間
  pmShiftMaxHour: 6,                 // 何時までを「午後」とみなすか
  assumeTodayWhenDateOmitted: true   // 時刻だけの場合に当日扱いするか
};
```

`src/Commands.gs` の `COMMAND_WORDS` でコマンドの言い回しを増やせます。

## テスト

外部依存がないため、ローカル（Node.js 18 以上）でそのまま実行できます。

```bash
cd line-calendar-bot
node test/run.js          # 日本語の日付・時刻の解析（120項目）
node test/integration.js  # Webhook受信→確認→登録→返信までの通し確認（56項目）
```

`test/integration.js` は `CalendarApp` や `UrlFetchApp` などの GAS のサービスを差し替えて実行するため、
実際の LINE やカレンダーには一切アクセスしません。

GAS エディタからは `Tests.gs` の `runParserTests()` で同様の確認ができます。
`tryParse("9/15 14:00 打合せ")` を実行すると、カレンダーに登録せずに解析結果だけを確認できます。
設定の確認は `Config.gs` の `checkConfiguration()` を実行してください。

## セキュリティ上の注意

- **Webhook URL は秘密情報です。** クエリの `token` が唯一の認証で、これを知る相手は誰でも
  あなたのカレンダーに予定を作れます。URL をそのまま他人に共有したり、公開の場に貼らないでください。
- Apps Script のウェブアプリは `doPost(e)` にリクエストヘッダを渡さないため、
  LINE が送る `X-Line-Signature` による署名検証は GAS 単体では実装できません。
  クエリの合言葉はその代替策です。より厳密に検証したい場合は、Cloud Functions などヘッダを
  読める環境に Webhook を移す必要があります。
- `ALLOWED_SOURCE_IDS` を設定すると、指定したトーク以外からの登録を拒否できます。
  外部の人が Bot を友だち追加しても予定を作れなくなるので、運用に入れる際は設定を推奨します。
- チャネルアクセストークンが漏れた場合は、LINE Developers コンソールから再発行してください。

## トラブルシューティング

| 症状 | 確認すること |
| --- | --- |
| Bot が何も返さない | LINE Official Account Manager で **応答メッセージがオフ／Webhook がオン** か。GAS の「実行数」にログが出ているか |
| 「合言葉が一致しない」とログに出る | Webhook URL の `?token=` が `WEBHOOK_TOKEN` と一致しているか |
| グループで反応しない | グループ参加が「許可する」になっているか。日付＋時刻が揃っているか（[どこから拾うか](#どこから拾うか誤反応の調整)）。先頭に `予定` を付ければ必ず登録します |
| グループで反応しすぎる | `GROUP_MIN_CONFIDENCE` を `high` のままにする。特定のトークだけ使いたい場合は `ALLOWED_SOURCE_IDS` を設定する |
| カレンダーに入らない | `CALENDAR_ID` が正しいか。GAS で `checkConfiguration()` を実行して確認 |
| コードを直したのに反映されない | **デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン「新バージョン」→ デプロイ** で再デプロイする |
| 時刻が 9 時間ずれる | GAS プロジェクトのタイムゾーンが「日本標準時」か |

## 制約

- グループの確認は 6 時間で期限切れになります（押すのが遅れた場合は投稿し直してください）。
- 1 メッセージで登録できるのは 10 件までです。
- `取消` で戻せるのは直前の 1 回分だけです。
- テキストメッセージのみ対象です（スタンプ・画像・ファイルは無視します）。
- 予定の変更（既存予定の書き換え）には対応していません。`取消` して登録し直してください。
